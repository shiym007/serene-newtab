# Serene · 极简新标签页

一款面向 Edge / Chrome 的新标签页扩展。无第三方依赖，数据全部保存在浏览器本地。

![version](https://img.shields.io/badge/version-1.6.0-8a7f6a) ![manifest](https://img.shields.io/badge/Manifest-V3-4a6b8c) ![license](https://img.shields.io/badge/license-MIT-56806a)

## 功能

### 时钟与日期

- 时钟字体四选一：衬线、纤细、等宽、简黑，切换带淡入淡出过渡
- 数字变化带过渡动画（自下浮现 + 溶解）；开启「显示秒数」后按秒更新，关闭时按分钟更新
- 可配置项：加粗、12/24 小时制、是否显示秒数、是否显示时钟
- 日期是独立元素，位置与大小可单独拖动缩放，与时钟互不干扰
- 日期格式通过占位符拼装，支持 10 个占位符，其余文字原样输出：

  | 占位符 | 含义 | 示例 |
  |---|---|---|
  | `{Y}` / `{y}` | 年份（数字 / 汉字） | `2026` / `二〇二六` |
  | `{M}` / `{m}` | 月份（补零 / 汉字） | `08` / `八` |
  | `{ME}` | 英文月份 | `AUGUST` |
  | `{D}` / `{d}` | 日期（数字 / 汉字） | `16` / `十六` |
  | `{W}` / `{w}` | 星期（全 / 简） | `星期日` / `周日` |
  | `{WE}` | 英文星期 | `SUNDAY` |

  例：`{y}年{m}月{d}日` → `二〇二六年八月十六日`

- 日期字体三选一（衬线 / 黑体 / 等宽）

### 搜索

- 基于 Bing，联想接口为 `api.bing.com/osjson.aspx`
- 本地搜索历史置顶展示，可逐条删除、一键清空，可整体关闭记录（保存于 `chrome.storage.local`）
- 通过内容脚本捕获任意来源的 Bing 搜索词（地址栏、Bing 站内搜索、含图片搜索），与新标签页历史合并
- 支持仅图标模式：搜索框收起为圆形，聚焦时展开；失焦自动收起
- 可配置项：搜索框宽度、联想条目数、透明度、在新标签页打开

### 背景

- 六款渐变预设：墨 / 黛 / 苔 / 绛 / 烬 / 雾
- 支持图片或 MP4 / WebM 视频：本地文件（≤120MB）或直链；图片自动压缩至最长边 2400px
- 可配置项：亮度、常驻模糊、聚焦模糊强度

### 布局

- 时钟、日期、搜索框及每个快捷方式图标均为独立可移动块
- 拖动调整位置，滚轮缩放，靠近屏幕中心提供磁性吸附
- 支持自定义吸附线：可添加多条，拖动线身移动、拖端点旋转角度（接近 0°/90°/180°/270° 自动吸附）；元素靠近时吸附到线上、沿线排列
- 位置以视口百分比存储

### 快捷方式

- 每个网站一个图标，位置与大小独立设置，名称显示可关闭，图标透明度可调
- 图标来源依次尝试：自定义图标 / 链接 → 站内 favicon（`.ico`、`.png`、`.svg`）→ 首字母底块
- 本地图标上传会压缩至 128px
- 聚焦搜索时图标淡出；可选「以搜索栏为中心向外」的顺序淡出

### 其他

- 设置面板按功能分七个分区：界面 / 时间 / 日期 / 背景 / 布局 / 快捷方式 / 搜索
- 动画基于 CSS transition 与 animation

## 安装

1. 下载本项目并解压（或 `git clone`）
2. 打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
3. 开启「开发人员模式」
4. 点击「加载解压缩的扩展」，选择 `serene-newtab` 文件夹
5. `Ctrl + T` 打开新标签页

> Edge 首次接管新标签页时若弹出提示，请选择「保留更改」。

## 使用速览

| 操作 | 说明 |
|---|---|
| 直接敲键盘 | 聚焦搜索框 |
| `↑` `↓` / `Enter` / `Esc` | 联想列表导航 / 搜索 / 关闭 |
| 设置 → 布局 → 进入编辑布局 | 拖动 / 缩放 / 居中吸附 |
| 编辑布局 → 添加吸附线 | 添加辅助线，元素拖近后沿线吸附 |
| 右上角齿轮 | 打开设置面板 |

## 隐私

- 所有数据保存在浏览器本地；设置走 `chrome.storage.sync`，大体积数据（背景、历史、快捷方式）走 `chrome.storage.local`
- 唯一的外部请求：Bing 联想接口（仅输入时携带关键词）
- 内容脚本仅注入 Bing 搜索结果页，只读取当前页搜索词，不读取页面内容
- 搜索历史与 Bing 账号云端历史无关

## 项目结构

```
serene-newtab/
├── manifest.json       # MV3 清单（新标签页接管 + storage + 内容脚本）
├── newtab.html         # 页面结构
├── newtab.css          # 样式
├── newtab.js           # 主逻辑（按功能模块组织的单文件 IIFE）
├── bing-history.js     # 内容脚本：捕获 Bing 搜索词
├── CHANGELOG.md        # 版本更新日志
└── icons/              # 16 / 32 / 48 / 128 扩展图标
```

无构建步骤。

## 开发说明

- MV3 + 原生 JS，无第三方依赖
- 性能处理：拖动过程使用 `requestAnimationFrame` 合帧并仅更新被拖动元素；列表渲染采用事件委托与 `DocumentFragment` 批量插入；日期串按天缓存
- 直接双击 `newtab.html` 可在浏览器中预览（自动回退 `localStorage`），但联想接口与内容脚本需在扩展环境中生效
