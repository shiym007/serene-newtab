## ✨ 为什么是 Serene？

打开浏览器的每个新标签页，不应该是千篇一律的广告和资讯墙。Serene 想给你的是——**按下 Ctrl+T 的那一瞬，世界安静下来**：

- 🕐 一屏之内的衬线大字时钟，秒针跳动都自带细腻动画
- 💭 随手一敲，Bing 联想 + 你的搜索历史精准置顶
- 🖼 换上一张图、一段动态视频，或干脆挑一款氛围渐变
- 🧲 把时钟、日期、搜索框、每个网站图标，摆成你想要的样子

**它极简，但绝不简陋。** 每一个像素、每一次动画、每一处设置，都经得起推敲。

## 🕰 时钟与日期

- **4 款字体样式**：衬线、纤细、等宽、简黑，切换带淡入淡出过渡
- ⏱ 每分钟数字跳变自带「自下浮现 + 溶解」动画
- 🪶 时钟加粗、12/24 小时制、秒数开关，随你配置
- 🎨 **日期是完全独立的自由块**——想放哪就放哪，和时钟互不干扰
- 🔣 **日期格式自定义引擎**：`{Y} {y} {M} {m} {ME} {D} {d} {W} {w} {WE}` 十个占位符任意拼，剩下的字原样显示

```
{Y} 2026    {y} 二〇二六    {M} 08    {m} 八    {ME} AUGUST
{D} 16      {d} 十六        {W} 星期日  {w} 周日  {WE} SUNDAY
```

> 例：`{y}年{m}月{d}日` → 二〇二六年八月十六日 · `{WE} {M}/{D}` → SUNDAY 08/16

## 🔎 搜索

- 🌐 基于 **Bing**，官方 OpenSearch 接口做**实时联想**
- 🕘 **搜索历史置顶**：本地记录排在联想词最前，断网也能翻出历史
- 📡 **全浏览器自动捕获**：地址栏搜的、Bing 页内搜的（含图片搜索），统统自动进历史，实时同步
- ❌ 历史可逐条删除、一键清空，或整体关掉记录
- 🪄 **仅图标模式**：平时收成一个圆形磨砂小图标，点击弹性展开输入
- 📏 搜索框宽度、联想条目数、透明度，全部可调
- 🖱 搜索 / 快捷方式「在新标签页打开」**两个独立开关**，点错也不慌

## 🖼 背景

- 🎨 6 款氛围渐变预设：墨 / 黛 / 苔 / 绛 / 烬 / 雾

- 🎞 胶片颗粒 + 暗角质感叠层，氛围感拉满

## 🧲 自由布局

- 🔲 时钟、日期、搜索框、每个快捷方式图标，统统是**独立可移动块**
- 🖐 拖动任意摆放，滚轮悬停缩放，靠近屏幕中心**磁性吸附**
- 📐 **自定义吸附线**：想沿一条 45° 斜线排图标？画一条线，元素拖过去自动吸附、沿线排列
  - 拖线身移动，拖端点旋转任意角度（0°/90° 自动磁吸）
- 💾 位置按屏幕百分比存储，换分辨率也不会乱

## 🔗 快捷方式

- 🧩 **每个网站一个独立图标**，位置、大小单独调整

- 🏷 名称显示可关，透明度可调

## 🎆 动画与细节

- 🌅 打开标签页的完整入场编排：壁纸淡入 → 主体依次浮现 → 顶栏下滑 → 图标错峰弹入

## 📥 安装

1. 📦 下载本项目并解压（或 `git clone`）
2. 🌐 打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
3. 🛠 开启「开发人员模式」
4. 📂 点击「加载解压缩的扩展」，选择 `serene-newtab` 文件夹
5. 🎉 `Ctrl + T` 打开新标签页，享受宁静

> 💡 Edge 首次接管新标签页时若弹出提示，选择「保留更改」。

## 🛡 隐私

本扩展**不收集、不上传任何数据**：

- 🔒 所有设置、历史、快捷方式、背景均存在浏览器本地（`chrome.storage.local`）
- 🌐 唯一外部请求：Bing 官方联想接口（仅在你输入时携带关键词）
- 🧩 内容脚本只注入 Bing 搜索结果页，仅读取当前页搜索词 `?q=`，不读页面内容
- 🧹 搜索历史与 Bing 账号云端历史无关，清空浏览器数据即彻底删除

## 📁 项目结构

```
serene-newtab/
├── manifest.json       # MV3 清单（新标签页接管 + storage + 内容脚本）
├── newtab.html         # 页面结构
├── newtab.css          # 全部视觉样式（纯 CSS，无框架）
├── newtab.js           # 主逻辑（时钟 / 搜索 / 布局 / 设置，模块化 IIFE）
├── bing-history.js     # 内容脚本：捕获任意来源的 Bing 搜索词
├── CHANGELOG.md        # 版本更新日志
└── icons/              # 16 / 32 / 48 / 128 扩展图标
```

🚀 **无构建步骤、无第三方依赖**——克隆即用，改完刷新扩展就能看到。

## 🧑‍💻 开发说明

- **MV3 + 原生 JS**：不引任何库，`newtab.js` 为单文件 IIFE（14 个功能模块）
- 💾 双存储策略：设置走 `storage.sync`（跨设备），大文件与历史走 `storage.local`
- ⚡ 性能细节：拖动 rAF 合帧、列表事件委托、日期按天缓存、`DocumentFragment` 批量插入
- 🌐 直接双击 `newtab.html` 可预览（自动回退 localStorage），但联想接口与内容脚本需扩展环境
