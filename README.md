# Serene · 极简新标签页

一个为 Edge / Chrome 打造的极简风格新标签页扩展：大字时钟、Bing 搜索联想、可自定义背景（含动态视频）、自由拖拽布局、独立快捷方式、自定义吸附线。**零依赖、零联网追踪、全部数据留在本地。**

## 特性

### 时钟与日期
- **时钟 4 款字体样式**：衬线（Palatino）、纤细、等宽、简黑，切换带淡入淡出过渡，加粗可开关
- 每分钟数字跳变自带「自下浮现 + 溶解」动画；时钟可整体关闭
- 12/24 小时制、秒数显示可开关
- **日期为独立自由块**：位置、大小单独拖拽缩放，与时钟完全解耦
- **日期格式自定义引擎**：`{Y} 2026 · {y} 二〇二六 · {M} 08 · {m} 八 · {ME} AUGUST · {D} 16 · {d} 十六 · {W} 星期日 · {w} 周日 · {WE} SUNDAY` 十个占位符任意组合，其余文字原样显示
- 日期字体三选（衬线 / 黑体 / 等宽）+ 加粗开关

### 搜索
- Bing 搜索 + **实时联想**（官方 OpenSearch 接口），联想条目数 5–12 可调
- **搜索框仅图标模式**：平时收起为圆形磨砂图标，点击弹性展开输入，失焦自动收起
- 搜索框宽度 360–900px 可调，透明度可调，联想栏宽度自动跟随
- **搜索历史置顶**：本地历史（时钟图标）排在联想词之前，断网也能出历史
- **全浏览器 Bing 搜索记录自动捕获**：地址栏搜索、Bing 页内搜索（含图片搜索）都会进入历史，通过内容脚本实现，实时同步
- 历史可逐条删除（联想条目悬停「×」）或清空，也可整体关闭记录
- 搜索 / 快捷方式「在新标签页打开」**两个独立开关**（关闭则当前页加载，Ctrl 点击始终新开）
- 聚焦搜索时背景**高斯模糊**（强度可调）

### 背景
- 6 款氛围渐变预设（墨 / 黛 / 苔 / 绛 / 烬 / 雾）
- 自定义图片：粘贴链接或上传本地（自动压缩至 2400px）
- **MP4 / WebM 动态视频背景**：本地（≤120MB）或直链，静音循环铺满，聚焦时同样模糊
- **壁纸亮度**（40%–120%）与**常驻模糊**（0–30px）独立调节，对渐变 / 图片 / 视频统一生效
- 胶片颗粒 + 暗角质感叠层

### 自由布局
- 时钟、日期、搜索框、每个快捷方式图标都是**独立可移动块**
- 拖动任意摆放，滚轮悬停缩放，靠近屏幕中心**磁性吸附**（带辅助线）
- **自定义吸附线**：可添加任意条辅助线，拖线身移动、拖端点旋转任意角度（0°/90° 自动磁吸）；元素靠近即吸附到线上，沿线自由排列
- 位置按屏幕百分比存储，分辨率变化自动适配

### 快捷方式
- **每个网站一个独立图标**，位置、大小单独调整，名称显示可关闭，透明度可调
- 图标多级回退：自定义图标 / 链接 → favicon（`.ico`/`.png`/`.svg` 依次尝试）→ 彩色首字母底块
- 支持图标链接或本地上传（自动压到 128px）
- 聚焦搜索时图标**错峰退场**，可选**以搜索栏为中心向外扩散消失**（径向模式），失焦后弹簧曲线依次弹回

### 动画与细节
- 打开标签页的完整入场编排：壁纸淡入 → 时钟 / 日期 / 搜索框依次浮现 → 顶栏下滑 → 图标错峰弹入
- 全部动画仅使用合成器属性（opacity / transform），GPU 完成，不触发重排

## 安装

1. 下载并解压本项目（或 `git clone`）
2. 打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
3. 开启「开发人员模式」
4. 点击「加载解压缩的扩展」，选择 `serene-newtab` 文件夹
5. `Ctrl + T` 打开新标签页即可

> Edge 首次接管新标签页时若弹出提示，选择「保留更改」。

## 使用速览

| 操作 | 说明 |
|---|---|
| 直接敲键盘 | 自动聚焦搜索框 |
| `↑` `↓` / `Enter` / `Esc` | 联想列表导航 / 搜索 / 关闭 |
| 设置 → 布局 → 进入编辑布局 | 拖动调整位置，滚轮缩放，双击快捷方式图标编辑 |
| 编辑布局 → 添加吸附线 | 拖端点旋转（自动吸水平/垂直），元素拖近即吸附到线上 |
| 右上角齿轮 | 打开设置面板（界面 / 时间 / 日期 / 背景 / 布局 / 快捷方式 / 搜索 七个分区） |

## 隐私

本扩展**不收集、不上传任何数据**：

- 所有设置、历史、快捷方式、自定义背景均存储于浏览器本地（`chrome.storage.local`）
- 唯一的外部请求：Bing 官方联想接口 `api.bing.com/osjson.aspx`（仅在你输入时携带关键词）
- 内容脚本仅注入 Bing 搜索结果页，只读取当前页搜索词 `?q=`，不读取页面内容
- 搜索历史与 Bing 账号的云端历史无关，清空浏览器数据即彻底删除

## 项目结构

```
serene-newtab/
├── manifest.json       # MV3 清单（新标签页接管 + storage + 内容脚本声明）
├── newtab.html         # 页面结构
├── newtab.css          # 全部视觉样式（纯 CSS，无框架）
├── newtab.js           # 主逻辑（时钟 / 搜索 / 布局 / 设置，模块化 IIFE）
├── bing-history.js     # 内容脚本：捕获任意来源的 Bing 搜索词
└── icons/              # 16 / 32 / 48 / 128 扩展图标
```

无构建步骤、无第三方依赖——克隆即用，改完刷新扩展即可见。

## 开发说明

- **MV3 + 原生 JS**：不引入任何库，`newtab.js` 为单文件 IIFE（14 个功能模块）
- 双存储策略：小体积设置走 `storage.sync`（跨设备），背景大文件与历史走 `storage.local`
- 性能设计：拖动 rAF 合帧 + 单元素精准写入、列表渲染全事件委托、日期串按天缓存、`DocumentFragment` 批量插入
- 直接双击 `newtab.html` 可在浏览器预览（自动回退 localStorage），但联想接口与内容脚本需扩展环境
- 图标由 PowerShell + System.Drawing 一次性生成（见 git 历史）
