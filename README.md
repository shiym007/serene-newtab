# 🌙 Serene · 极简新标签页

**按下 Ctrl+T 的那一秒，世界安静下来。**

一款为 **Edge / Chrome** 打造的极简新标签页扩展：衬线大字时钟、Bing 智能联想、可自定义图片 / 动态视频背景、能自由拖拽的自由布局，以及一整套细节微调。

> 🔒 无第三方依赖　🔒 无联网追踪　🔒 所有数据留在本地

## 🕰 时钟与日期

- **四种字体样式**：🪶 衬线（Palatino）· 纤细（Segoe UI Light）· 等宽（Cascadia Mono）· 简黑（Bahnschrift），切换时带淡入淡出过渡
- ⏱ **数字变化动画**：时间跳变时，变化的数字会「自下浮现 + 轻微溶解」；开启「显示秒数」后**逐秒**跳动，关闭则按**每分钟**更新
- 🎚 时间可配置：**加粗**、12/24 小时制、显示秒数、整体显示 / 隐藏时钟
- 🧲 **日期是独立元素**：位置、大小与时钟完全解耦，可单独拖动缩放；字体三选一（衬线 / 黑体 / 等宽）+ 加粗
- 🔣 **日期格式完全可定制**——用占位符任意拼装，其他文字原样输出：

  | 占位符 | 含义 | 示例 |
  |---|---|---|
  | `{Y}` / `{y}` | 年份 · 数字 / 汉字 | `2026` / `二〇二六` |
  | `{M}` / `{m}` | 月份 · 补零 / 汉字 | `08` / `八` |
  | `{ME}` | 英文月份 | `AUGUST` |
  | `{D}` / `{d}` | 日期 · 数字 / 汉字 | `16` / `十六` |
  | `{W}` / `{w}` | 星期 · 全 / 简 | `星期日` / `周日` |
  | `{WE}` | 英文星期 | `SUNDAY` |

  > 例：`{y}年{m}月{d}日` → **二〇二六年八月十六日** · `{WE} {M}/{D}` → **SUNDAY 08/16**

## 🔎 搜索

- 🌐 基于 **Bing**，联想来自官方接口 `api.bing.com/osjson.aspx`，输入即实时联想（150ms 防抖 + 请求中断控制）
- 🕘 **历史置顶**：本地搜索历史排在最前（带时钟图标），断网也能翻出历史；联想框会自适应屏幕，不会跑出边缘
- 📡 **全浏览器自动捕获**：地址栏搜索、Bing 站内搜索（含图片搜索）都会被内容脚本记录，与新标签页历史合并、实时同步
- ❌ 历史管理：联想条目悬停「×」**逐条删除**、设置里一键**清空**、或整体**关闭记录**
- 🪄 **仅图标模式**：搜索框平时收成一个圆形磨砂小图标，点击弹性展开，失焦自动收起
- 🎛 搜索可配置：**宽度**（360–900px）、**联想条目数**（5–12）、**透明度**、**在新标签页打开**

## 🖼 背景

- 🎨 **六款渐变预设**：墨 / 黛 / 苔 / 绛 / 烬 / 雾
- 🖼 **自定义图片**：粘贴链接，或上传本地（自动压缩至最长边 2400px）
- 🎬 **动态视频背景**：MP4 / WebM，本地上传（≤120MB）或直链，静音循环铺满全屏
- ☀️ 背景三重调节：**亮度**（40%–120%）、**常驻模糊**（0–30px）、**聚焦模糊**强度（8–40px）
- 🎞 叠加胶片颗粒质感与暗角，跑上一段动态视频逼格直接拉满

## 🧲 自由布局

- 🔲 时钟、日期、搜索框、每个快捷方式图标——统统是**独立可移动块**
- 🖐 编辑模式下：拖动任意摆放，**滚轮悬停缩放**，靠近屏幕中心自动**磁性吸附**（带辅助线提示）
- 📐 **自定义吸附线**：一键添加，可存多条
  - 拖线身 / 中心点 = 移动整条线
  - 拖两端圆点 = 绕中心旋转任意角度，接近 0°/90°/180°/270° 自动磁吸
  - 🧩 元素拖近吸附线会自动**吸附到线上、沿线自由排列**——沿一条斜线排图标不再是难题
- 💾 所有位置按**视口百分比**存储，换分辨率也不乱

## 🔗 快捷方式

- 🧩 **每个网站一个独立图标**，位置、大小单独调整，互不影响
- 🏷 名称显示可整体关闭，图标**透明度**可调
- 🎯 图标多级回退：自定义图标 / 链接 → 站内 favicon（依次尝试 `.ico` / `.png` / `.svg`）→ 彩色首字母底块，保证不空白
- 📤 支持本地上传图标（自动压缩至 128px）
- 🌀 聚焦搜索时图标淡出；可选**以搜索栏为中心向外扩散**的顺序淡出（径向模式），失焦后弹簧式依次弹回

## 🎆 细节与随手小当

## 📥 安装

1. 📦 下载本项目并解压（或 `git clone`）
2. 🌐 打开 `edge://extensions`（Edge）或 `chrome://extensions`（Chrome）
3. 🛠 开启「开发人员模式」
4. 📂 点「加载解压缩的扩展」，选择 `serene-newtab` 文件夹
5. 🎉 `Ctrl + T`，享受一页宁静

> 💡 Edge 首次接管新标签页时若弹出提示，选「保留更改」。

## 🛡 隐私

本扩展**不收集、不上传任何数据**：

- 🔒 全部数据保存在浏览器本地（`Edge` / `Chrome` 的 `storage`）；其中设置走 `chrome.storage.sync`，大体积数据（背景、历史、快捷方式）走 `chrome.storage.local`
- 🌐 唯一外部请求：Bing 联想接口 `api.bing.com/osjson.aspx`（仅在你输入时才携带关键词）
- 🧩 内容脚本只注入 Bing 搜索结果页，仅读取当前页搜索词，不读取页面内容
- 🧹 搜索历史与你的 Bing 账号云端历史无关，清空浏览器数据即彻底清除

## 🧑‍💻 开发说明

- **MV3 + 原生 JS**，不引入任何库
- 💾 双存储策略：设置走 `storage.sync`（跨设备同步），大文件与历史走 `storage.local`
- ⚡ 性能细节：拖动 `requestAnimationFrame` 合帧 + 仅更新被拖元素；列表渲染用事件委托 + `DocumentFragment` 批量插入；日期串按天缓存，避免每秒重复计算
- 🌐 直接双击 `newtab.html` 可预览（自动回退 `localStorage`），但联想接口与内容脚本需在扩展环境中生效
